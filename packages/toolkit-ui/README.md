# ZadLoop Toolkit UI

Presentation companion bundled by ZadLoop Ultimate Toolkit. It adds readable **5-hour** and **weekly** subscription quota remaining percentages to the composer dock, with an inline quick-summary popover that never navigates away from the chat. It automatically selects the connected provider that exposes those limits, applies scoped modern styling to `dsh-plugin-oauth-subs`, and normalizes the toolkit's Transfer and session-mode icons.

It contains no authentication code and never reads or stores OAuth tokens.
